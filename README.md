# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 双路专页

页眉入口进入「双路专页」：登记拱顶左右两支测缝计的配对（断面、左支编号、右支编号、差值门槛），并汇总拒收例子总表。

- 测量员一次交左右两路；左右差值绝对值越过门槛即整份退回，写明「双路超差」，不进待认领队列。
- 配对随单冻结：上报时把左支、右支、门槛快照进报告，事后改登记表，旧单配对仍冻结。
- 进队与配对冻结并进一次提交（同一事务锁定配对行后落单）；断面唯一约束保证两人同时抢同一配对至多成功一笔。
- 巡检员可看配对与差值，不许改配对也不能上报。
- 验收：先给甲断面绑左右（门槛 3.0），报 1.2 / 1.3 进待认领；报 1.2 / 4.8 退回（双路超差）。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
