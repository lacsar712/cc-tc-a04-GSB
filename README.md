# 隧道收敛测缝台

测量员一次提交某断面拱顶**左右两路**测缝读数。提交前该断面必须已在「双路专页」登记左右支配对（对不上不许进队）；左右差值绝对值越过登记表门槛即整份退回并写明**双路超差**。配对随单冻结：登记表事后改动，旧单仍按提交时的快照判定。进队和配对冻结并进一次提交，两人同时抢同一配对至多成功一笔。巡检员能看配对和差值，不许改配对也不能报。接口进程内后台线程认领待判行（不另起 worker 容器），按单路绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 双路流程

1. 页眉入口进「双路专页」，登记断面的左支编号、右支编号、差值门槛（专页内含配对登记表与拒收例子总表）。
2. 测量员一次提交该断面左右两路读数：
   - 断面未登记配对 → 拒绝进队；
   - `|左 - 右|` 越过门槛 → 整份退回（状态「退回」），写明双路超差，并进入拒收例子总表；
   - 否则进队为「待认领」，由认领线程判合格/超限（单路 ±3.0 mm）。
3. 提交成功的那一刻，左支/右支/门槛随单冻结；之后在双路专页改登记表，旧单配对仍冻结。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| GET | `/api/logs` | 记录列表（含差值与随单冻结配对，登录即可） |
| POST | `/api/logs` | 双路提交（仅测量员；超差 422 并写明双路超差） |
| GET | `/api/pairings` | 配对登记表（登录即可） |
| POST | `/api/pairings` | 登记配对（仅测量员；同断面唯一，并发抢同一配对至多一笔） |
| PUT | `/api/pairings/<id>` | 改登记表（仅测量员；不影响已冻结旧单） |
